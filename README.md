# kublesoft.net

Mirror of the website of **Kuble Soft**, the Talas games house of 1988 to 2007: [kublesoft.net](https://kublesoft.net/).

Texts and images belong to the site's owner; questions about its services go to them, not to the mirror.

Part of the [Irad Web Mirror](https://github.com/IRAD-WEB-MIRROR).
